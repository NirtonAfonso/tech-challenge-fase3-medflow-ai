# Artefatos

Diretório para resultados pequenos e versionáveis, como:
- métricas em CSV/JSON;
- figuras finais;
- matrizes de avaliação;
- manifestos de experimentos;
- diagramas exportados.

Pesos de modelos, checkpoints e arquivos grandes não devem ser commitados diretamente. Registrar no README/relatório o local e o procedimento de reprodução/download.
